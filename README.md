# AI Engineering Course

Lecture notes and practical exercises covering AI engineering fundamentals — from programming and data science foundations to building agentic AI systems.

The course site is built with [MkDocs](https://www.mkdocs.org/) and available at:
**https://faixanpervaix.github.io/ai-engineering-notes/**

## Quick Start

```bash
uv run mkdocs serve    # start live-reload dev server
uv run mkdocs build    # build static site to build/
uv run mkdocs gh-deploy  # deploy to GitHub Pages
```
